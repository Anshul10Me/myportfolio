🌐 Anshul – Personal Portfolio Website

This is my personal portfolio website built using HTML, CSS, and JavaScript.
It showcases my profile, skills, projects, and contact details in a modern and responsive design.

📩 Contact Form Setup (EmailJS)

This project uses EmailJS to send messages directly from the contact form.

To use it:

Create an account on EmailJS.

Create a service and template.

Replace:

emailjs.init("YOUR_PUBLIC_KEY")

service_id

template_id

Deploy your site.
